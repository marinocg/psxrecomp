# PSn00bSDK Advanced Hello ISO (PSX)

This demo mirrors PSn00bSDK's "basic graphics" sample pattern: explicit render context,
double buffering, ordering tables, primitive packets, and debug font rendering.

## Build

```bash
cd examples/demos/advancedhello
make
```

Outputs:
- `ADVHELLO.EXE`
- `ADVHELLO.iso`
- `ADVHELLO.cue`

## Clean

```bash
make clean
```
